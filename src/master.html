กุญแจหลักล็อกลิงก์ที่พาไปถึงข้อมูลของคุณ (ลิงก์แอป, ชีต, โปรเจกต์) ใครจะสำรองข้อมูลหรือ deploy จาก GitHub ต้องพิมพ์กุญแจนี้ The Master Key locks the links that lead to your data (app link, Sheet, project). Backups and deploys from the GitHub repo need this key.

⚠️ ลืมกุญแจ: เจ้าของบัญชี Google รัน startMasterKeySetup() ใน editor เพื่อตั้งใหม่ได้ Forgot it? The Google account owner can run startMasterKeySetup() in the editor to set a new one.
