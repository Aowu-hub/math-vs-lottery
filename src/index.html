Math vs. Lottery

แอปนี้ใช้สถิติความถี่ของตัวเลขจากผลสลากกินแบ่งรัฐบาลย้อนหลังหลายปี มาคำนวณและสุ่มสร้างชุดเลขนำโชค (รางวัลที่ 1 / เลขหน้า 3 ตัว / เลขท้าย 3 ตัว / เลขท้าย 2 ตัว) เพื่อความสนุกด้านสถิติเท่านั้น This app uses real historical Thai Government Lottery digit-frequency stats to generate playful "lucky draw" number sets (1st Prize / Front 3 / Back 3 / Back 2) — for statistics-for-fun, nothing more.

ผลสลากกินแบ่งรัฐบาลออกแบบสุ่มอิสระทุกงวด แอปนี้ไม่ใช่เครื่องมือพยากรณ์จริง และไม่ควรใช้เป็นคำแนะนำในการซื้อ Every real draw is independently random. This is not a real prediction tool and shouldn't be used as buying advice.

วงล้อสร้างเลขอย่างไร · How the wheel generates numbers
เลขแต่ละหลักถูกสุ่มแบบมีน้ำหนัก (weighted-random) จากความถี่ที่ตัวเลขนั้นเคยออกจริงในตำแหน่งเดียวกัน ไม่ใช่การเลือกเลขที่มีโอกาสสูงสุดเสมอไป — คณิตศาสตร์แค่โน้มโอกาส ไม่ได้กำหนดผล Each digit is a weighted-random pick based on how often that digit has really appeared in that exact position historically — not always the single most likely digit. Math leans the odds, it doesn't fix the draw.
